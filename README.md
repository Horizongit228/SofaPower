# SofaPower ⚡

Простое Android-приложение для включения домашнего ПК по Wake-on-LAN (WoL).

## Как устроена схема

Телефон подключён к домашнему роутеру по Wi‑Fi, а ПК — к тому же роутеру Ethernet-кабелем. Это типичная схема для Wake-on-LAN.

Приложение:
1. Берёт MAC-адрес Ethernet-адаптера ПК.
2. Определяет IPv4-сеть телефона и её broadcast-адрес автоматически.
3. Собирает стандартный WoL magic packet: 6 байт `FF`, затем MAC-адрес ПК 16 раз.
4. Трижды отправляет пакет по UDP на порт 9.

## Что нужно включить на ПК

### BIOS/UEFI
Ищи один из похожих пунктов:
- Wake on LAN
- Power On By PCI-E / PCIe
- Resume By PCI-E Device
- PME Event Wake Up

Если есть `ErP/EuP`, для WoL из полного выключения его часто нужно отключить, потому что ErP может снимать дежурное питание с сетевого адаптера.

### Windows
`Диспетчер устройств → Сетевые адаптеры → Ethernet-адаптер → Свойства`

Во вкладке **Дополнительно** включи, если доступно:
- Wake on Magic Packet
- Shutdown Wake-On-Lan

Во вкладке **Управление электропитанием** включи:
- Разрешить этому устройству выводить компьютер из ждущего режима
- Разрешать вывод компьютера только с помощью магического пакета

## Где взять MAC-адрес ПК

В cmd/PowerShell:

```text
ipconfig /all
```

Найди **Physical Address / Физический адрес** именно Ethernet-адаптера.

## Автоматическая сборка APK

GitHub Actions автоматически собирает debug APK после каждого изменения в ветке `main`. Готовый файл появляется в артефакте `SofaPower-debug-apk` внутри соответствующего workflow run.

Проект использует Android Gradle Plugin 8.13.2, Gradle 8.13, compileSdk/targetSdk 36 и JDK 17.
